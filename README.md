# 午托点名 PWA v1.2（单次点名版）

iPhone 优先的午托班点名小应用：一天点名一次，状态只有 **到 / 请假 / 值日**；断网可用，数据只存在手机本机（IndexedDB），不依赖任何服务器和账号。

## 功能一览

| 模块 | 能力 |
|---|---|
| 点名 | 日期切换（前后一天 / 日期选择器）、**顶部固定状态栏（到 / 请假 / 值日）**、双列大名片、点一下即标记、**未点名的始终在上、已点名的沉底（两组内按年级排序）**、长按改状态、搜索、按状态筛选、进度条、底部各状态计数、**连续撤销最近 20 步** |
| 名单 | 新增/编辑（姓名、分组、序号、备注、头像拍照或相册选图自动压缩到 200×200）、停用/启用（停用不参与点名但保留历史）、删除二次确认、批量粘贴导入（每行 `姓名` 或 `姓名,分组`，自动跳重名）、导出名单 CSV |
| 记录 | 按日查看（有记录的日期倒序）、单人最近 60 天历史、月度统计（各状态次数 + 出勤率）、导出记录 CSV（UTF-8 带 BOM，Excel 打开中文不乱码）、JSON 全量备份导出/恢复 |

状态口径：**出勤率 =（到 + 值日）÷ 应点次数**；应点次数 = 该月该生所有记录条数。一天只记一条，不再区分午餐 / 午休。

## 一、部署（二选一，都要 HTTPS）

### 方式 A：GitHub Pages

1. 新建一个 GitHub 仓库（如 `wudian`），把本目录的 `index.html`、`manifest.webmanifest`、`sw.js`、`icons/` 上传到仓库根目录。
2. 仓库 **Settings → Pages**，Source 选 `main` 分支 `/ (root)`，保存。
3. 等 1~2 分钟，访问 `https://<你的用户名>.github.io/wudian/` 即为成品地址。

### 方式 B：Cloudflare Pages

1. 登录 [pages.cloudflare.com](https://pages.cloudflare.com) → **Create a project → Direct Upload**。
2. 把本目录（含 `icons/` 子目录，不含 `screenshots/`、`tmp/`）拖进去，项目名随意（如 `wudian`）。
3. 点 **Deploy**，得到 `https://wudian.<你的子域>.pages.dev`。

> 部署后升级：改了文件就把 `sw.js` 顶部的 `VERSION` 换一个新号（如 `wudian-v1.0.1`）再上传，旧缓存会自动清除。

## 二、iPhone 添加到主屏幕

1. 用 iPhone **Safari** 打开部署地址。
2. 点底部中间「分享」按钮 → **添加到主屏幕**。
3. 桌面出现绿色对勾图标「午托点名」，打开即全屏（无浏览器地址栏）。
4. 首次打开联网加载一次后，**断网也能正常打开和点名**，数据全部在本机。

## 三、备份与恢复

- **备份**：记录页 →「数据」分段 → **全量备份 JSON**，得到一个包含学生、头像、全部记录、设置的 JSON 文件。可存到 iCloud / 微信文件收藏等任意位置。
- **恢复**：记录页 →「数据」→ **恢复备份**，选择之前导出的 JSON，确认后**覆盖**现有数据。恢复前请先导出一份当前数据以防误操作。
- **换手机**：旧手机备份 JSON（隔空投送/微信传输均可）→ 新手机装好应用后恢复即可。
- 建议：每周五放学后备份一次。

## 四、常见问题

**Q：断网后打开是白屏 / 打不开？**
第一次必须联网打开一次，让 Service Worker 缓存外壳。之后断网可用。若仍异常，联网刷新一次再断网试。

**Q：换了个浏览器 / 清了 Safari 数据，数据没了？**
数据存在浏览器本机存储里，清除网站数据会清掉点名记录。定期导出 JSON 备份。

**Q：Excel 打开 CSV 中文乱码？**
本应用导出的 CSV 自带 BOM，Excel 双击直接打开中文正常。若用其他工具另存过导致乱码，重新从应用里导一次。

**Q：误点了怎么撤销？**
点名页底部有「撤销」按钮，可连续撤销最近 20 次操作；长按学生卡片也可改状态或清除本次记录。

**Q：学生毕业/退班了，删除还是停用？**
建议**停用**：不参与点名和统计，但历史记录保留。删除会连历史记录一起清掉，需二次确认。

**Q：iPad / 安卓能用吗？**
可以。安卓 Chrome 菜单里「添加到主屏幕/安装应用」即可；iPad 同样支持。只是布局按 iPhone 竖屏优先设计。

**Q：一个人一天会记几条？**
一天一条。状态只有「到 / 请假 / 值日」，未标记即视为「未点」；换日期互不影响。

## 目录结构

```
午托点名/
├── index.html            应用主体（CSS/JS 全内联，零外链）
├── manifest.webmanifest  PWA 清单
├── sw.js                 Service Worker（cache-first 预缓存外壳）
├── icons/                180 / 192 / 512 三尺寸图标
├── screenshots/          自测截图（点名页 / 名单页 / 记录页）
├── README.md             本文件
└── tmp/                  开发自测脚本与临时文件（部署时无需上传）
```

## 技术说明

- 数据存储：IndexedDB（学生 / 记录 / 头像 blob），localStorage 仅存界面偏好（日期、当前状态笔）。
- 头像：`<input type="file" accept="image/*" capture="user">` 拍照/选图 → canvas 居中裁方 200×200 → JPEG 质量 0.75 → 存 IndexedDB。
- 离线：`sw.js` cache-first 预缓存外壳；升级改 `VERSION` 常量。
- 隐私：无任何网络请求（Service Worker 自身除外）、无 CDN、无统计、数据不出设备。
